# Data sources

SkyPilot never asks a language model for game facts. Every price, requirement, recipe, drop
rate and XP value comes from one of these sources, and the UI labels which one
(`DataSource`: Profile, Hypixel, NEU-REPO, Registry, Heuristic, Market, Mod).

| Source | Used for | Refresh |
|---|---|---|
| Hypixel API `/v2/resources/skyblock/{items,skills,collections,election}` | item names, tiers, NPC prices, **requirements** (skill, slayer, dungeon, HOTM, collection, garden, Kuudra, Crimson reputation…), museum data, gemstone slots, skill caps, collection tiers, mayor/perks | `skypilot-api sync-data`, on start when older than `DATA_REFRESH_HOURS`, and every `DATA_REFRESH_HOURS` |
| Hypixel API auctions / auctions_ended / bazaar / firesales / news | market data | collector |
| Hypixel API profiles / museum / garden | player data | only when the user analyses |
| [NotEnoughUpdates-REPO](https://github.com/NotEnoughUpdates/NotEnoughUpdates-REPO) (MIT) | XP tables (skills, catacombs, slayers, HOTM/HOTF, pets), HOTM/HOTF cost formulas, crafting/forge/Kat/NPC recipes, slayer drop tables, minion tiers, talisman upgrade chains, essence costs | same as resources (tarball download, path-traversal checked) |
| `data/registry/*.toml` (curated, this repo) | values the APIs do not expose, each with a source URL and check date (Hypixel SkyBlock Wiki, EliteFarmers): AH/Bazaar fees, MP per rarity, slayer gear tiers, dungeon floor requirements, Kuudra reputation, mining targets, crop constants, money method definitions, calendar events | edited by hand; `cargo test` validates every item id against the real item list |
| [SkyHanni-REPO](https://github.com/hannibal2/SkyHanni-REPO) (MIT) `constants/island_graphs/*.json` | named public places on 19 islands (NPCs, warps, zones, forges…), used as guide waypoints. Only named nodes are kept; collectible tags (`fairy_soul`, `hoppity`, `rift_enigma`) and dev-only nodes are dropped, and so are the graph edges (no route finding) | same as resources; licence copied to `data/cache/skyhanni/LICENSE` |
| `data/registry/guides.toml` (curated, this repo) | progression guides (Dwarven Mines, Crimson Isle, The Rift): step texts with wiki sources, the SkyHanni place each step points at, and a "done" check against the analysed profile (HOTM, skills, faction, reputation, timecharms) | edited by hand; `cargo test` checks that every waypoint resolves |
| `data/registry/calendar.toml` (curated) | SkyBlock calendar constants, seasonal events and the recurring Dark Auction (every 3 SkyBlock days at midnight = :55) and Jacob's Farming Contest (every 3 days, 1 day long = :15-:35), each with a wiki source and check date; served to the mod at `/api/mod/calendar` | edited by hand |
| [SkyHanni-REPO](https://github.com/hannibal002/SkyHanni-REPO) (MIT) `constants/SeaCreatures.json` | sea creature names, the chat line announcing each, rarity and fishing XP (rare sea creature alert, fishing tracker); served at `/api/mod/sea-creatures` | with the island graphs |
| [SkyHanni](https://github.com/hannibal002/SkyHanni) chat filters (reference only) | wording of the Hypixel chat lines the mod's optional chat features recognise (lobby joins, warps, profile ID, kill combo, ability hits, GEXP, [Sacks], RARE/PET DROP, SLAYER QUEST, "is now available!", treasure chests and powder rewards, dungeon healing/damage lines, [BOSS], GOOD/GREAT CATCH, TROPHY FISH), sidebar lines ("Time Elapsed:", "Cleared:", "The Catacombs (F7)") and tab widget names ("Commissions:", "Powders:", "Forges:", "Crystals:", "Pet:", "Trophy Fish:", "Composter:", "Pests:", "Jacob's Contest:", "Bank:", "SB Level:"…), checked Oct 2026; no code is copied | when Hypixel changes a message |
| `data/translation/dictionary.toml` | protected SkyBlock terms and phrase translations | edited by hand |
| `data/farms/*.json` | reference farm layouts (generated by `scripts/fixtures/mkfarms.py`) | edited by script |

## Unknown, unverified and heuristic values

- A value that cannot be confirmed is left out and shown as **Unknown** (e.g. Catacombs XP for
  floors not verified on the wiki).
- Profile sections disabled in the player's API settings are `Unknown: Not available from API`.
- Heuristics (floor readiness, money-per-hour ranges, run times, uptime) are labelled
  **Heuristic** and given a confidence below "high".
- Market numbers carry freshness ("Updated N seconds ago", **STALE DATA**) and confidence with
  reasons (sample size, volatility, manipulation flags).

## Profile schema (checked against live responses, Oct 2026)

- Heart of the Mountain lives in `skill_tree` (`experience.mining`, `nodes.mining`,
  `tokens_spent.mountain`, `selected_ability.mining`); powder is still in `mining_core`
  (`powder_<type>`, `powder_spent_<type>`). The API omits zero values, so when `skill_tree` is
  present a missing field means 0. With no mining XP, no mining node and no `mining_core`, HOTM
  is reported as **locked** (level 0), not Unknown. Older profiles with only `mining_core`
  are still read.
- Purse is `currencies.coin_purse`; the bank needs the Banking API setting.

## Item valuation (networth, tooltips, liquidation)

- Price keys separate exotic pieces: leather armour whose stored colour
  (`ExtraAttributes.color`) differs from the default colour in the Hypixel items resource gets
  its own key (`…|exotic=r:g:b`), so collector listings (30M-550M for Lapis pieces worth ~2k)
  never price the normal item. Dyed items (`dye_item`) are priced normally.
- Fair value from listings alone needs at least 3 BIN listings; one or two asks with no sale
  give no value ("not enough data").
- An owned item valued from the auction house is capped at the cheapest current listing (an
  owner has to undercut it) and, with fewer than 3 recorded sales, at its crafting cost when
  every ingredient has a Bazaar/NPC price; it never goes below the NPC sell price.
- When ≥10% of networth rests on low-confidence valuations, the analysis says so and names the
  items. Liquidation entries with such prices are marked "price unconfirmed".
- Income estimates only use a compacted form (e.g. Enchanted Melon) when one hour of output is
  at most 5% of that product's daily Bazaar volume; thin products are skipped.
