# Visual Studio

Minecraft 26.2 / Fabric向けの、SkyPilot単体で利用できるローカル画面演出です。ホームの **Visual Studio** または `/skypilot visual` から開きます。追加演出はすべて初期状態でオフです。

| 機能 | 設定・操作 |
| --- | --- |
| ズーム | 有効化してCを長押し。2 / 4 / 8 / 12倍、滑らかな移行の切替、倍率に連動するマウス感度。キーはMinecraftの操作設定で変更 |
| キルパーティクル | Spark / Heart / Soul / Flame、8〜96粒子 |
| ヒットマーカー | 受信した自分の攻撃を250ms表示 |
| コンボ | 8秒以内の連続キルを表示 |
| 低体力の枠 | 体力30%未満で赤い画面枠 |
| カスタムクロスヘア | Dot / Cross / Ring、6色。標準の攻撃クールダウン表示を維持 |
| 方位HUD | 8方向と角度 |
| シェーダー | None / Cinematic / Warm / Cool / Mono / Sketch |
| リセット | 追加演出をオフにして初期設定へ |

## 内蔵シェーダー

実際のGPU後処理で、彩度・色調・コントラスト・ビネットを変更します。Sketchは近傍の画素から輪郭を強調します。Minecraft標準のポストエフェクト機構を利用し、追加modは不要です。

外部シェーダーパックを読み込む機構や、影・水面反射を描画するエンジンは含みません。外部エフェクトが動作中は上書きせず、無効化やワールド退出時はSkyPilotが設定したエフェクトだけを解除します。

## キル演出の判定

クライアントが受信したダメージの攻撃者が自分だった場合に対象を記録し、8秒以内の死亡で演出します。他者からのダメージが届けば記録を取り消します。記録は128体まで、死亡演出は対象ごとに一度です。攻撃者情報が省略されるサーバーや独自戦闘では動作しない場合があり、サーバーの正式なキル認定との一致は保証しません。

演出・コスメは自分の画面だけに表示します。攻撃や移動を自動操作する機能はありません。

## 設定と確認

`config/skypilot.json` の `visuals` に保存します。不正な倍率・粒子数を範囲内へ戻し、未知のプリセット名は既定値へ戻します。画面を開いている間はズームを解除します。

単体テストで壊れた設定の復元を、Minecraftクライアントテストで5種類のシェーダー、解除、外部エフェクトの保持、ズームと感度、死亡演出の重複防止を確認します。全サーバー・全GPUでの互換性を確認したという意味ではありません。
