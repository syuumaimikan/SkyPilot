# 暗視・出品状況・クラフトフリップ（0.1.6）

- MODの「Visual studio → 暗視」で切り替え。キー設定の「暗視の切り替え」は初期状態では未割当。描画の光源マップのみ変更し、サーバーのポーション効果や動画設定は変更しません。
- Webの「マーケット → 出品・注文状況」(`/market/orders`) に自分のAHとバザーの状態を表示。AHは分析済みのMinecraft UUIDに対するHypixel APIの結果を約1分間隔で取得。売却済み、期限切れ、出品中を区別し、API障害時は前回値と確認日時を表示。
- バザーの個人注文は公開APIで取得できません。MODを同じWebアカウントへ `/skypilot link` で連携し、`Your Bazaar Orders` を開くと表示中のページを同期。約定済み・注文中と単価を表示。全ページ・全履歴ではなく最終確認ページです。ゲームを閉じると更新が止まり、2分を超えた情報は古い情報として表示。消えた注文を売却済みと推測しません。ロード中の空ページも前回値を消しません。
- 注文の読取・保存は認証済みアカウント単位。MODの送信には端末トークン必須。PostgreSQL利用時はmigration 0004で永続化、メモリストアではAPI再起動で消えます。
- MODのJメニューに「クラフト」を追加。材料費、売値、手数料控除後利益、ROI、信頼度、レシピ材料、必要条件を表示。
- Webのクラフトに予算・最低信頼度・最低販売数・価格変動の余裕のフィルタを追加。初期値は50M、信頼度0.5、1販売/日、価格変動5%。MODも5%売値下落・5%材料高の条件で利益が残る候補を表示します。
- レシピツリーの孫以下の材料数量も倍率を伝播。循環・深さ依存の失敗を別経路にキャッシュしない、不正な価格や数量は除外、材料末端まで信頼度を確認。
- AHフリップは購入候補より安い競合出品も考慮。既にある安い出品を無視して利益を過大表示するケースを修正。

価格は試算です。複数個できる材料のクラフトは余剰の再利用を前提とする場合があります。自動購入、出品、受取は行いません。

API仕様: https://api.hypixel.net/ （auctionはplayer指定、bazaarは商品単位の板情報）。
