# キー設定と便利HUD

## キーを変更する

ホームの「キー設定」、Visual Studioの「キー設定」、または `/skypilot keys` で開きます。

1. 変更したい機能の右側にあるキー名をクリックします。ページの矢印で機能を切り替えられます。
2. キーボードのキー、またはマウスボタンを押すと割り当てて保存します。
3. 入力待ちのEscは変更を取り消します。割り当てをなくす場合は「×」、初期キーに戻す場合は「復元」（英語表示: Reset）をクリックします。

Minecraft標準のキーと同じ割り当てなら「競合」を表示します。行にマウスを重ねると、競合する機能の一覧と省略されていない名前を確認できます。競合は警告のみで、既存のキーを勝手に解除しません。「Minecraftの操作設定」で他のキーも変更できます。

割り当てはMinecraft標準の `options.txt` に保存し、標準の操作設定と同期します。単独のキーボードキー・マウスボタンに対応します。OSが予約しているショートカットの動作はOSに依存します。

## 割り当てられる機能

| 機能 | 初期割り当て |
| --- | --- |
| ズーム | C（ズーム機能の有効化が必要） |
| SkyPilotメニュー | J |
| SkyPilot設定、HUDエディター | 未割り当て |
| ワードローブ、ツールデスク、パズル、演出スタジオ | 未割り当て |
| 便利HUD設定、キー設定、描画設定 | 未割り当て |
| 座標コピー | 未割り当て |
| シェーダー切り替え | 未割り当て |
| ランダムコーデ | 未割り当て |
| 集中タイマー停止／再開 | 未割り当て |

新規ショートカットはプレイ中、画面を開いていないときに使えます。チャットやインベントリで入力したキーを新規ショートカットとして処理しません。新規キーを初期状態で未割り当てにして、既存の操作と重ならないようにしています。

シェーダー切り替えはNone → Cinematic → Warm → Cool → Mono → Sketch → Noneの順です。ランダムコーデは現在のコスメを変更するので、残したいコーデは先にワードローブで保存してください。タイマー停止／再開は、デスクで開始済みのタイマーに作用します。

## 便利HUD

ホームの「便利HUD」、または `/skypilot utility` で設定します。各表示は初期状態でオフです。

- 座標: ブロック座標XYZ。
- FPS: Minecraftが計測するFPS。
- 通信遅延: Minecraftのプレイヤー情報にある遅延値。サーバー側の送信値に依存します。
- 時計: クライアントのローカル時刻。
- 移動速度: クライアントの水平速度から算出した概算m/s。
- 道具の耐久値: メインハンドの耐久値。対象がなければオフハンド、どちらもなければ「—」。
- 空きスロット: ホットバーを含む36スロットの空き数。防具・オフハンドは除外します。
- 集中タイマー: デスクで開始したタイマーの残り時間。
- プレイ時間: ワールド接続からの経過時間。アプリ停止をまたいで保存しません。
- ゲーム内時刻: クライアントが持つワールドの標準時計から算出。

左右の配置と背景を切り替えられます。ゲームのHUDを隠したときや、画面を開いている間は追加HUDを表示しません。「HUDをすべてオフ」は表示を無効にし、左右・背景の設定は保持します。既存HUDとの自動整列は未対応です。

座標コピーはローカルのクリップボードだけに書き込み、チャットへの送信や移動操作を行いません。
