# プレイラボ

ホームまたはメニューの「プレイラボ」(`/tools`)を開きます。実測値・確認した単価を入力して使う16のツールです。

| 番号 | 用途 |
|---|---|
| 01–04 | 実測DPSと攻撃所要時間、必要攻撃数、回復を含む耐久時間、マナ補充なしの使用回数 |
| 05–08 | 休憩を含む周回予定、全周回の経費資金、純利益・純時給、パーティの均等分配 |
| 09–12 | 基本数量と周回消耗品の補給表、所持数を引いた買い足し、必要スロット・不足量、単価を使った買い物小計 |
| 13–16 | 装備変更前後の実測値、増加1単位あたり費用、短縮時間、実測時給で換算した時短価値と費用回収周回 |

戦闘・周回は一定のダメージとペースを仮定し、特殊効果・確率・無敵時間を推測しません。戦闘のHPは討伐なら敵、耐久なら自分の値を入力して別のシナリオで計算してください。周回は最後の周回後に休憩を加算しません。1周もできない場合は初期費用を加算せず、収支は0です。

持ち物の必要数は `基本数量 + 1周の消費数 × 周回数`、買い足しは `max(0, 必要数 - 所持数)` です。アイテムや属性が異なるものは別々の行にしてください。スタック上限はゲーム内で確認して入力します。スロット計算は持参予定分だけで、バッグ全体をAPIから取得しません。単価0の買い足しは未入力として件数を表示し、小計へ含めません。最大60行です。

装備比較の費用回収は、短縮時間を実測の純時給で換算した機会価値からの試算です。実際に受け取る利益ではありません。時短がない・遅くなる・時給0の場合は回収周回を不明と表示します。

入力は端末内にプロフィール別で保存します。他の端末へ自動同期しません。バックアップJSONをコピーし、別の端末でプレビュー後に復元できます。形式・数値・件数・重複IDを検証し、読めない保存内容を自動で上書きしません。直前の変更は取り消せます。

検証: `node scripts/test-play-lab.mjs`、Webの型チェック・Lint・本番ビルド。
