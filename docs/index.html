GET STARTED

導入と使い方

01

Minecraft 26.2 + Fabric

対応するFabric Loaderを導入し、ビルドしたSkyPilotのmod JARをmodsへ。Fabric APIはJARに同梱しています。公式Minecraftの利用権が必要です。

02

Visual Studioを開く

ホームのVisual Studio、または /skypilot visual。演出は初期状態ではオフ。使いたい機能を有効にしてください。

03

自分らしく設定

/skypilot wardrobe でコスメ、/skypilot desk で道具、/skypilot puzzle でパズル、/skypilot perf で描画設定を開きます。

シェーダーの対応範囲

内蔵の画面後処理です。外部シェーダーパックの読み込み、リアルタイム影、反射、水面の描画エンジンは含みません。他のポストエフェクトが動作中はSkyPilotが上書きしません。オフにするとSkyPilotのエフェクトだけを解除します。

キル演出の判定と表示範囲

自分が攻撃者として含まれる受信ダメージと、8秒以内の対象の死亡を利用します。攻撃者情報を省略するサーバーや独自戦闘では動作しない場合があります。サーバーのキル認定と完全には一致しません。コスメ・演出は自分のクライアントだけに表示されます。

設定を元に戻す

Visual Studioの「演出をリセット」で演出をオフにできます。ズームキーはMinecraftの操作設定で変更できます。画質プリセットはPerformance画面の「元に戻す」で復元できます。
