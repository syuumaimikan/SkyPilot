# 追加機能ロードマップ

以下は追加候補です。**未実装**の項目を利用可能な機能として扱わず、優先順位は実装・互換性調査の結果に合わせて見直します。

実装済み: ズーム、5種類のGPU画面シェーダー、4種類のキルパーティクル、ヒットマーカー、コンボ、低体力枠、カスタムクロスヘア、方位表示、無料ワードローブ、3Dスキン、保存コーデ、集中タイマー・メモ・計算・乱数・ToDo・2048、手動パズル支援。操作は [Visual Studio](client-effects.md) と [ドキュメントホーム](index.html) を参照。

## 優先候補

| 候補 | ユーザーにとっての価値 | 完了条件 |
| --- | --- | --- |
| 全設定の検索 | 大量の機能からすぐ探せる | 日英の表示名・説明で検索でき、設定へ移動できる |
| キー競合通知 | ズームなどの操作が重なる理由が分かる | 同じキーの機能を表示し、操作設定へ案内する |
| 設定プロファイル | 軽量・撮影・普段用を切り替える | 保存・適用・削除と失敗時の復元、バージョン移行を確認 |
| HUDスナップ配置 | 見栄え良く揃えられる | 整列・余白・解像度変更・元に戻すを確認 |
| コントラスト・文字サイズ | 小さな画面でも読みやすい | キーボード操作と最小対応解像度で欠けない |
| モーション軽減 | 動きの多い演出を控えられる | UI・ズーム・コスメの動きをまとめて調整できる |
| エフェクト強度 | シェーダーを好みに調整できる | 彩度・コントラスト・ビネットの上限とリセットがある |

## コスメ・楽しみ

| 候補 | 内容 | 完了条件 |
| --- | --- | --- |
| コーデ共有ファイル | 自分のコーデをファイルで交換 | 型・サイズ・未知のアイテムを検証、読み込み前に試着 |
| 新しいマント柄 | 星空、雲、幾何学、季節のオリジナル柄 | 素材の権利を確認し、遠近・動作時の見え方を検証 |
| 試着用ポーズ集 | ローカルで立ち姿や撮影ポーズを選ぶ | サーバーの移動や当たり判定を変更しない |
| 試着の背景・照明 | 明暗の異なる背景でコスメを見る | コスメの色が判別でき、設定を復元できる |
| コスメのアニメーション | 翼やマントの動きを増やす | FPS負荷の上限と動きの無効化がある |
| スクリーンショットアルバム | 撮影した画像を探しやすくする | 日時・お気に入り・保存先表示、削除前の確認 |
| 日替わり手動パズル | ログインのたびに小さな楽しみ | 解ける問題生成、難易度、ヒント、答え確認 |
| 2048のチャレンジ | 自己ベスト更新を楽しむ | スコア履歴、再開、壊れた保存データの復旧 |

## 便利な小機能

| 候補 | 内容 | 完了条件 |
| --- | --- | --- |
| 集中タイマー履歴 | 今日の集中時間と達成回数 | 日付変更・中断・再起動・二重計上を検証 |
| 目標チェックリスト | 複数の目標をまとめる | 並べ替え・アーカイブ・入力保存失敗の通知 |
| 持ち物メモ | 自分で必要なアイテムを書き留める | 検索・チェック・取り消し、上限で入力を失わない |
| セッションメモ | 前回の続きから遊べる | ワールド別の手動メモを区別して保存 |
| 通知センター | タイマーなどの通知を見返す | 通知履歴、既読、音と表示の個別設定 |
| 計算履歴・単位換算 | 同じ計算を繰り返さずに済む | 式の再利用、エラー表示、コピー操作 |
| プロファイルのバックアップ | 設定を安全に持ち運ぶ | 秘密情報を除外し、復元前に差分を表示 |

## 調査が必要な描画機能

- FPS・フレーム時間履歴: 実測データと計測負荷を表示し、改善を比較できる。
- 画質プリセットの比較: 適用前後の設定を示し、変更を復元できる。
- 色覚補助: シミュレーションで可読性を評価し、強度と無効化を用意する。
- 外部シェーダー連携: 対応Minecraft版・描画API・ライセンスを調査する。対応確認前にパック互換を宣伝しない。
- 撮影用画面演出: レターボックス・粒子の強度などを、通常プレイへ戻せる形で検討する。

## 品質の基準

設定は初期状態・無効化・復元・破損データ・小さな解像度で確認します。表示だけの機能も実際のクライアントで検証し、計測していない性能向上や未確認の互換性を約束しません。新規候補は既存機能の不具合修正と並行して優先順位を見直します。
