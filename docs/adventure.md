# 冒険ノート

メニューの「冒険ノート」または `/planner` から開きます。Androidアプリでも同じ画面が使えます。

| 番号 | ツール |
|---|---|
| 01–04 | 日課・週課チェックリスト、優先度、分析結果からタスク作成、プレイ時間に収まる計画 |
| 05–06 | 集中タイマーと計測時間の記録フォームへの引き継ぎ |
| 07–10 | プレイ記録、実測の収支・時給、週間振り返り、活動別比較 |
| 11–12 | XP・コレクション・コインの数値目標と実測ペースからの到達時間 |
| 13–14 | 欲しい物の予算と購入済みチェック |
| 15–16 | 装備セットの保存と比較 |
| 17–19 | タグ付きメモ、検索・ピン留め、生産などの手動タイマー |
| 20 | JSONバックアップとプレビュー付き復元 |

端末のブラウザ保存領域に、分析したプロフィール別で保存します。未分析時のノートは手入力用の別領域です。他の端末へ自動同期しません。ブラウザデータの削除やアプリ再インストールに備え、バックアップJSONをコピーして保管してください。復元は表示中のプロフィールのノートを置き換えます。直前の変更は「直前の変更を戻す」で取り消せます。他のタブで変更された場合は上書きを避けます。

日課は端末の午前0時、週課は月曜日にリセットします。ゲームのリセット時刻と同一とは限りません。集中タイマー・生産タイマーは絶対時刻から残り時間を計算し、再読み込み後も継続します。完了表示は画面を開いている間のみで、スマホのバックグラウンド通知は行いません。

収入・費用・XP・価格・装備は確認した数値を手入力します。収支は収入から費用を引いたもの、時給は記録した時間に対する実績です。目標の到達時間は実測ペース未入力なら不明と表示します。欲しい物の単価未入力分は小計から除外し、未入力件数を表示します。売買やゲーム操作は実行しません。

保存件数上限は、タスク100・プレイ記録300・育成目標100・欲しい物100・装備セット30・メモ100・生産タイマー100です。復元時は形式・数値・重複ID・件数・サイズを検証し、読めない保存内容を自動で上書きしません。

## 自分のAH

`/market/orders` は分析済みのMinecraftユーザーの公開AHデータを表示します。AHはAPI、バザーは連携MODが最後に確認した内容です。取得時刻・データ元・終了時刻・最高入札額・回収済み状態を確認でき、検索と状態による絞り込みに対応します。

入札式は終了前の入札があっても出品中、BINは支払いがあれば売却済みと判断します。期限切れかつ入札なしは未売却で、表示価格は利益に含みません。未回収の売却額は手数料差し引き前です。古い観測には注意表示が付き、APIから行が消えたことだけで売却を判定しません。出品IDがあれば `/viewauction` コマンドをコピーできます。ゲーム内で手動で実行してください。
