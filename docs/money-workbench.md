# 金策ワークベンチ

「その他 → 金策ワークベンチ」、または「金策 → 16の金策ツールを開く」から利用します。URLは`/money/workbench`です。プロフィール分析なしでも市場を使うツールは動作します。

| 番号 | 新しいツール | 内容 |
|---|---|---|
| 1 | 横断金策レーダー | バザー・NPC・クラフト・フォージ・Kat・AHを元手・ROI・信頼度で絞り込み |
| 2 | お気に入り | プロフィール別に候補を端末へ保存。相場から消えた候補は除外 |
| 3 | 資金バスケット | 残す資金、商品別上限、商品数、数量上限から配分。商品重複と古い相場を除外 |
| 4 | 注文価格の競争 | 買い注文の上乗せ・売り注文の値下げによる純利益の変化 |
| 5 | 取引量の上限 | 週間取引量への参加率・取引時間・元手から数量を制限 |
| 6 | ストレステスト | 売値下落、仕入れ上昇、追加費用を同時に試算 |
| 7 | 損益分岐 | 税・追加費用込みで損失が出ない売値 |
| 8 | 利確価格 | 目標利益を得るための売値 |
| 9 | 損失上限 | 許容損失に対応する売値 |
| 10 | 目標価格の監視 | この画面を開いている間、即時購入・即時売却の価格到達を表示 |
| 11 | 一括クラフト | 回数に応じた元手・生産数量・税引き後利益 |
| 12 | 買い物リスト | 直接の材料を集計し、価格不明を明示。コピー可能 |
| 13 | フォージ・Kat計画 | 解放枠、拘束資金、日数、完了サイクルで生産を計画 |
| 14 | 燃料の投資判断 | 実測収入増加と消耗型燃料の相場から追加利益・採算価格を計算 |
| 15 | 採集量の相場換算 | 実測個数/時を即時売却税と消耗品費を含む純時給へ換算 |
| 16 | ドロップの周回計画 | 確率・周回費用・通常報酬から期待値、出ない確率、95%到達周回数、必要資金 |

相場は既存の市場APIから30〜60秒ごとに取得します。商品選択は名前・アイテムIDで検索でき、同名のエンチャント本はIDで区別します。元手は`50m`、`1.5b`などで入力できます。

候補の利益は、その価格で購入・生産・売却できた場合の計算です。週間取引量は将来の約定を保証しません。フォージ・Katは完成品を売却してから同じ元手を次のサイクルへ回す仮定です。クラフトは1回単位、バザーは1個単位、AHは1出品単位で計算します。レシピ条件がある候補は確認済みチェックを付けてから資金配分に含めます。ドロップは独立試行を仮定し、RNGメーターや確定報酬の補正は含みません。

ブラウザ保存はお気に入りのみです。監視は画面表示中の到達表示で、バックグラウンド通知ではありません。注文・購入・売却・ゲーム操作を自動実行する機能は含みません。
